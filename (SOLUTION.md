# Solución — Examen Práctico
## Qué se implementó
-Se realizó inicialmente la verificacion que el proyecto compilara de forma correcta, sin embargo se evidencio que existian unas dependencias mal implementadas y por ende
se dió solución primero a estos errores.
-Se realiza la creacion del endpoint /delete/{id} y ademas se hace la configuracion para poder consultar en swagger
## Cómo se implementó
-Se realizaron las validaciones correspondiente a los errores y se valido con posible documentacion como superar dichos errores
-Se realiza la implementacion y configuracion del servicio solicitado con las condiciones solicitadas, usando IA para generacion de codigo base pero con ajustes a la 
solicitud planteada de tal forma que estuviera dentro de los parametros establecidos de codigo validado
## Cambios en base de datos / configuración
-Unicamente se realizó el ajuste sobre las configuracion del pom, desde las cuales se tenian varias problemas con la definicion de spring-starter y de lombok
-A nivel de BD no se realizó ningun ajuste debido a que se valida el script y no se ve nada raro para corregir
## Dificultades encontradas
-El tiempo de configuracion de algunas partes del ambiente tienden a generar demoras
-No contaba con algunas de las herramientas que se requieren para validar el front por ende le di mas prioridad al backend
## Mejoras que podrían aplicarse
-Quedan pendientes los cambios a nivel de front, debido a que el tiempo fue limitado y me tomo bastante tiempo el poder compilar el backend de manera correcta iniciando el examen
